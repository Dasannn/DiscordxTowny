## What this is

A plugin that a Minecraft server operator installs on their own server. It
connects to a Discord server using a bot token that the operator creates and
holds. There is no service run by the authors: nothing phones home, and the
authors cannot see, reach or administer any installation.

## Acceptable use

Do not use this software to harass people, to evade a ban from Discord, or to
break Discord's terms. The bot acts with the permissions an operator gives it; it
is the operator who decides what it may touch.

## Updates

The plugin can check this repository for new releases and download them, verified
against the checksum published with the release. That behaviour can be disabled.
Installing an update is the operator's decision, and a release that changes
configuration in a breaking way is never applied without confirmation.
